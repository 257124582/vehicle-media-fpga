# 车载乘客信息终端 v3 功能使用手册

适用 HX4S20C 开发板及本次交付的 vehicle_media.bit。手册供日常操作和竞赛演示使用；不需要先阅读 RTL 代码。版本日期 2026年10月16日。

## 一 快速启动

工程目录为本代码包解压目录。已经正常运行时，可直接进行下面的按键操作；断电后需要重新下载 SRAM 程序。

1. 断电后插入已准备好的 TF 卡，板卡 HDMI_B 接显示器 HDMI 输入；USB-JTAG 和 USB-UART 接电脑，再接通板卡电源。显示器选择对应的 HDMI 输入源。

2. 双击工程目录中的 download_sram.cmd。正常下载信息包含器件 EG4S20BG256 和 SRAM_DOWNLOAD_COMMAND_COMPLETED；随后等待图片装载完成。此入口写 SRAM，不写 Flash。

3. 默认显示首站东门、日间主题和图片轮播，轮播间隔默认 5 秒。串口号以设备管理器中的CH340端口为准，命令中的COM5为示例。

## 二 常用按键速查

| 按键操作 | 普通显示页中的作用 |
| --- | --- |
| 短按 K2 NEXT 后松开 | 切换到下一张图片 |
| 短按 K4 AUTO 后松开 | 开启或暂停自动轮播 |
| 短按 K3 MODE 后松开 | 循环切换六种图像处理模式 |
| 长按 MODE 约 0.8 秒 | 进入或退出设置菜单 |
| 长按 NEXT 约 0.8 秒 | 进入应急画面；再次长按解除 |
| 长按 AUTO 约 0.8 秒 | 切换日间和夜间主题 |

短按在松开后生效。长按只执行长按功能，不会在松开时额外触发短按。菜单打开时，NEXT 和 AUTO 用于调节菜单，不执行普通页快捷操作。

# 设置菜单

长按 MODE 进入菜单；短按 MODE 依次选择项目，最后一项之后返回第一项。NEXT 减少、AUTO 增加；开关类项目按任一键切换。长按 MODE 退出。

| 项目 | 范围和用途 |
| --- | --- |
| 1 亮度 | −128 至 127；每次约调节 8。调整时自动切回原图模式。 |
| 2 对比度百分比 | 0 至 300%；步长约 12.5%。100% 为正常；调整时自动切回原图模式。 |
| 3 音量 | 0 至 15；0 为静音，默认 8。 |
| 4 滚动字幕 | 0 关、1 开；关闭后停止并隐藏底部滚动文字。 |
| 5 音频波形 | 0 关、1 开；在技术展示页观察实际 PCM 波形。 |
| 6 连续测试音 | 0 关、1 开；用于检查声音链路，演示后建议关闭。 |
| 7 淡入淡出 | 0 关、1 开；控制图片切换转场，默认开启。 |
| 8 当前站编号 | 1 至 6；NEXT 上一站，AUTO 下一站，端点不循环。 |
| 9 昼夜模式 | 0 日间、1 夜间；切换主题和对应图像参数。 |
| 10 技术展示页 | 0 车载乘客页、1 技术展示页。 |
| 11 应急演示 | 开启应急后菜单自动关闭；长按 NEXT 解除。 |
| 12 重新扫描 | 按 AUTO 执行 TF 图片重扫；NEXT 不执行。 |

## 参数记忆规则

日间和夜间各自保存一组亮度、对比度。例如先切夜间、调暗，再切回日间，日间设置仍保留；再次切夜间恢复刚才的夜间参数。日间默认亮度 0、对比度 100%；夜间默认亮度 −48、对比度约 87.5%。

所有参数只保存在本次运行的寄存器中。复位、断电或重新下载后恢复默认值，不会保存到 TF 卡。夜间功能调整输出画面，不控制显示器背光；本版没有环境光传感器。

菜单内长按 NEXT 或 AUTO 只调整一次，不连续加减，也不会触发应急或昼夜快捷动作。调整后若想演示其他图像模式，先退出菜单，再短按 MODE。

# 车载场景使用方法

本版以校园接驳车为演示场景。站点由按键或串口手动推进，不代表真实 GPS 定位或车辆运行数据。

## 线路与到站提示

线路顺序：东门 → 教学楼 → 图书馆 → 食堂 → 宿舍区 → 西门。普通显示页包含当前站、下一站、日夜状态、六站路线进度和底部滚动文字。到达西门时显示终点，不再提供下一站。

操作：长按 MODE → 短按 MODE 选择“当前站编号” → AUTO 前进一站或 NEXT 后退一站 → 长按 MODE 退出。改变站点触发约 3 秒的到站提示和短提示音。站点不会随图片轮播自动推进。

## 应急提示与恢复

普通页长按 NEXT，屏幕显示红色应急画面，并触发专用提示音。应急优先于图片、到站提示和故障页面；当前图片编号、轮播计时及转场进度被冻结。提示音是短音，不是持续警笛或语音播报。

再次长按 NEXT 解除应急，原播放状态继续；如果进入应急前轮播已暂停，解除后仍保持暂停。应急期间普通切图、模式切换和菜单操作被屏蔽。音量为 0 时应急也保持静音，红色画面仍显示。

## 昼夜切换

在普通页长按 AUTO，观察主题及图片亮度变化。原图、灰度、二值化和边缘模式使用渐变调色；专用亮度和对比度模式直接使用相应处理参数。需要直观演示昼夜效果时，先选原图模式。

## 建议的现场演示流程

1. 展示中文线路页和四张图片轮播，说明 TF 读图、缓存和 HDMI 显示链路。

2. 在菜单中把站点改为教学楼，展示当前站、下一站、进度条和到站短音。

3. 退出菜单，长按 NEXT 进入应急；稍后再次长按，展示原播放恢复。

4. 长按 AUTO 切夜间，再在菜单中调节亮度，展示日夜独立记忆。

5. 打开技术展示页，展示图像处理模式、字幕和 PCM 波形。结束时关闭连续测试音、解除应急并退出菜单。

# 图像和音频功能

车载乘客页适合正常展示；技术展示页用于观察原有图像处理、图片尺寸、状态信息和音频波形。在菜单中打开“技术展示页”即可切换。

| 模式编号 | 功能 | 操作提示 |
| --- | --- | --- |
| 0 | 原图 | 显示彩色图片，适合常规车载演示。 |
| 1 | 灰度 | 将彩色图像转换成灰度。 |
| 2 | 二值化 | 按阈值显示黑白，可用串口调节阈值。 |
| 3 | Sobel 边缘 | 显示图像边缘；边界像素作边界处理。 |
| 4 | 亮度处理 | 按当前亮度参数增减像素亮度。 |
| 5 | 对比度处理 | 按当前对比度参数调整图像反差。 |

退出菜单后短按 MODE 按 0→1→2→3→4→5→0 循环。亮度与对比度默认值可能使专用模式看起来与原图相近；需要先调节参数再比较。

## 对比显示与自适应阈值

串口发送 COMPARE 1 开启左右对比：左侧为处理前参考，右侧为所选模式，中央有分界线。发送 COMPARE 0 恢复整幅显示。后级全局调色仍可能影响参考侧；做原图对比时，建议先设置日间、BRIGHT 0、CONTRAST 256。

发送 MODE 2 进入二值化；THRESH 128 设置手动阈值。ADAPTIVE 1 根据图像平均灰度更新阈值；ADAPTIVE 0 回到手动阈值。自适应阈值是图像处理功能，不是自动环境感光。

## 图片缩放与转场

不同尺寸的合规 BMP 自动适配 640×480 输出区域，并按比例缩放；纵横比不匹配时出现黑边。NEXT 控制图片，站点菜单控制车站，两者互不等同。TRANSITION 1 开启淡入淡出，TRANSITION 0 直接切换。

## 音频及波形

声音通过 HDMI 输出，显示器需要内置扬声器或有效的音频输出设备，并取消静音。本版播放合成 PCM 提示音，不播放 TF 卡上的 MP3 或 WAV 文件，也不是人声报站。

检查声音时，把音量设为 8，打开“连续测试音”。打开“技术展示页”和“音频波形”可观察实际 PCM 波形；波形不是频谱或 FFT。检查完成后关闭连续测试音。正常模式仅在图片切换、到站或应急等事件发生时发声，平时安静属于正常现象。

# 串口命令参考

连接 USB-UART，使用实际 CH340 端口。本次为 COM5。参数为 115200 波特率、8 数据位、无校验、1 停止位，无流控。命令使用大写，每行以 LF 换行结尾；发送一条后等待回复。

| 命令 | 参数或用法 |
| --- | --- |
| STATUS / DETAIL / VEHICLE | 无参数；分别查询基本、扩展、车载状态。 |
| NEXT | 无参数；下一张图片。 |
| AUTO 0 或 1 | 关闭或开启轮播。 |
| PERIOD 1..60 | 轮播间隔，单位秒。 |
| MODE 0..5 | 选择上一页所列图像模式。 |
| THRESH 0..255 | 手动二值化阈值，默认 128。 |
| BRIGHT -128..127 | 当前日夜组的亮度参数。 |
| CONTRAST 0..768 | 当前组对比度；256=100%，不是百分数输入。 |
| VOLUME 0..15 | 音量；0 静音，8 为默认。 |
| TRANSITION 0 或 1 | 关闭或开启淡入淡出。 |
| COMPARE 0 或 1 | 关闭或开启左右对比。 |
| ADAPTIVE 0 或 1 | 关闭或开启自适应二值化阈值。 |
| RESCAN | 无参数；重新扫描和装载 TF 图片。 |
| TESTAUDIO 0 或 1 | 关闭或开启连续测试音。 |
| TICKER 0 或 1 | 关闭或开启滚动字幕。 |
| WAVE 0 或 1 | 关闭或开启音频波形。 |
| EMERGENCY 0 或 1 | 解除或进入应急。 |
| NIGHT 0 或 1 | 日间或夜间。 |
| STATION 0..5 | 东门至西门；串口编号比菜单显示少 1。 |
| VIEW 0 或 1 | 车载乘客页或技术展示页。 |

执行命令通常回复 OK，非法命令或参数回复 ERR。查询回复 S: 加 48 个十六进制字符，可用 tools/decode_status.py 解码。应急期间优先只使用 STATUS、DETAIL、VEHICLE、VOLUME 和 EMERGENCY 0；解除后再调整普通播放与站点。

示例：依次发送 STATION 1、NIGHT 1、EMERGENCY 1、EMERGENCY 0，即可演示教学楼站、夜间和应急恢复。每条命令单独占一行。不要同时让多个串口工具占用 COM5。

# 素材维护与常见问题

保持已验证的 TF 卡内容即可正常使用，无需因为升级 v3 而重新格式化。更换素材前保留原来的四张示例图，便于恢复演示。

## 更换图片

先断电取出 TF 卡，通过读卡器连接电脑。使用 FAT32，将合规 BMP 放在根目录；仅取扫描到的前四张有效图，顺序以文件系统扫描为准，不保证按文件名排序。建议根目录只保留需要的四张图片。

图片要求：24 位 BI_RGB BMP；宽度 1 至 1024 像素，高度 1 至 768 像素，文件不超过 4 MiB。不支持直接把 JPG 或 PNG 改扩展名为 BMP。工程 assets/tf_card_extended 目录提供已验证的四图素材。安全弹出读卡器后插回板卡，再上电下载；重新扫描可从菜单最后一项按 AUTO 或串口 RESCAN 触发。

## 常见问题速查

| 现象 | 处理方法 |
| --- | --- |
| 断电后没有 v3 画面 | 本版当前为 SRAM 下载，重新执行 download_sram.cmd。Flash 尚未固化验收。 |
| 黑屏或无信号 | 检查 HDMI_B、显示器输入源、板卡供电和下载是否成功。 |
| 中文丢失或异常 | 先使用随包已验证的 bit；自行重编译请用 rebuild.cmd 保留字体 ROM 初值。 |
| 有图但没有声音 | 检查显示器音量和扬声器；设音量 8，打开连续测试音检查。 |
| 按键功能与预期不同 | 检查是否在菜单或应急页；先退出菜单或长按 NEXT 解除应急。 |
| 夜间调节影响不了日间 | 两组参数独立；先切换到目标日夜状态再调节。 |
| 只有部分图片或读卡报错 | 检查 FAT32、BMP 格式与大小；恢复示例图并重新扫描。 |
| 拔卡后图片仍在播放 | 已装载图片保存在缓存；本版不持续检测拔卡。 |
| 无法打开 COM5 | 在设备管理器确认实际端口，并关闭其他串口软件。 |

## 工程文件与恢复

project/vehicle_media.al 为 TD 工程；build/td/vehicle_media.bit 为已验收功能的程序；download_sram.cmd 用于下载；rebuild.cmd 用于重新编译。建议先使用现成 bit，不需要为了日常操作重新编译。
